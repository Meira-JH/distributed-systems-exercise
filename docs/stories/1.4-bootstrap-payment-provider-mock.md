# Story 1.4: Bootstrap The Payment Provider Mock

## Epic

[Epic 1: Run The System Locally](/Users/jm/Documents/Github/Meira-JH/distributed-systems-exercise/docs/epics/1-run-system-locally.md)

## Status

`not ready`

This story should wait until the workspace bootstrap story has established the repo and local runtime conventions.

## Goal

Create a minimal payment-provider mock service that starts locally and exposes a basic readiness endpoint.

## Problem

The stack needs a lightweight external-service simulator so the local environment reflects the intended distributed topology from the beginning.

## Scope

This story includes:

1. `apps/payment-provider/package.json`
2. `apps/payment-provider/tsconfig.json`
3. service startup entrypoint
4. `/mode` or `/health` endpoint

This story does not require full provider behavior simulation yet.

## Deliverables

1. `apps/payment-provider/src/server.ts`
2. `apps/payment-provider/src/modes.ts`
3. one readiness endpoint

## Acceptance Criteria

1. the payment-provider service starts in Docker
2. `GET /mode` or `GET /health` returns a successful response
3. logs confirm that the mock provider is ready

## Dependencies

1. Story 1.1 completed

## Final Task

Create or update the necessary documentation inside `docs/` to reflect any setup steps, behavior, commands, or operational notes introduced by this story.

## Out Of Scope

1. payment idempotency simulation
2. flaky modes
3. email provider behavior
