# Story 1.7: Configure The NGINX Gateway

## Epic

[Epic 1: Run The System Locally](/Users/jm/Documents/Github/Meira-JH/distributed-systems-exercise/docs/epics/1-run-system-locally.md)

## Status

`not ready`

This story depends on the API service and core local stack wiring being available first.

## Goal

Configure NGINX as the local reverse proxy gateway so requests can route to both API replicas.

## Problem

The local environment needs a realistic entrypoint that mirrors the intended distributed system shape. Without the gateway, we cannot verify replica routing or later scaling behavior.

## Scope

This story includes:

1. `docker/nginx/default.conf`
2. upstream configuration for `api-1` and `api-2`
3. forwarded headers
4. health check routing through the gateway

This story does not require advanced production gateway features.

## Deliverables

1. `docker/nginx/default.conf`
2. Compose wiring for the `gateway` service

## Acceptance Criteria

1. NGINX listens on port `8080`
2. requests proxy to `api-1` and `api-2`
3. `curl http://localhost:8080/health` succeeds
4. forwarded headers are preserved for downstream services
5. the gateway container starts successfully in Docker Compose

## Dependencies

1. Story 1.2 completed enough for `/health`
2. Story 1.1 completed

## Out Of Scope

1. advanced rate limiting
2. TLS termination
3. production hardening
