# Story 1.8: Add Local Smoke Verification

## Epic

[Epic 1: Run The System Locally](/Users/jm/Documents/Github/Meira-JH/distributed-systems-exercise/docs/epics/1-run-system-locally.md)

## Status

`not ready`

This story depends on the stack components being runnable before smoke verification can be finalized.

## Goal

Create a simple verification flow so a developer can prove the local stack is working after setup.

## Problem

A local system is only useful if someone can quickly tell whether it is healthy. The project needs a short, explicit smoke-test path that does not require reading source code.

## Scope

This story includes:

1. exact startup commands
2. exact migration and seed commands
3. exact health-check commands
4. documentation updates needed to verify success

This story does not require full automated test coverage.

## Deliverables

1. smoke verification instructions in the docs
2. clear expected outcomes for each verification command

## Acceptance Criteria

1. the docs show how to start the stack locally
2. the docs show how to run migrations and seed data
3. the docs show how to verify:
   gateway, both API replicas, payment-provider, and worker startup
4. a new developer can follow the steps without tribal knowledge

## Dependencies

1. Stories 1.2 through 1.7 completed enough to verify locally

## Out Of Scope

1. comprehensive integration tests
2. load testing
3. exercise-specific scenario validation
