# Story 1.6: Add Seed Data

## Epic

[Epic 1: Run The System Locally](/Users/jm/Documents/Github/Meira-JH/distributed-systems-exercise/docs/epics/1-run-system-locally.md)

## Status

`not ready`

This story depends on the shared TypeORM database layer and migration flow being available first.

## Goal

Create a local seed script that inserts the minimum data needed to exercise the system after startup.

## Problem

Even if the system boots successfully, it is not useful for local practice without baseline users and permissions that can be reused across manual tests.

## Scope

This story includes:

1. `scripts/seed.ts`
2. at least one admin user
3. at least one normal user
4. minimum related permissions for local testing

This story does not require a sophisticated fixture system.

## Deliverables

1. `scripts/seed.ts`
2. documented seed behavior

## Acceptance Criteria

1. `npm run db:seed` succeeds against local PostgreSQL
2. the script creates at least:
   `admin@example.com` and `user@example.com`
3. the script inserts the minimum related permissions
4. rerun behavior is either idempotent or clearly documented

## Dependencies

1. Story 1.5 completed

## Out Of Scope

1. large fixture datasets
2. scenario-specific seed data for later exercises
