# Story 1.5: Add The Shared Database Layer

## Epic

[Epic 1: Run The System Locally](/Users/jm/Documents/Github/Meira-JH/distributed-systems-exercise/docs/epics/1-run-system-locally.md)

## Status

`not ready`

This story depends on the workspace, env-var, and local PostgreSQL baseline from Story 1.1.

## Goal

Create the shared TypeORM package with the first migration and the initial entities required to boot the system locally.

## Problem

Both the API and worker depend on a consistent shared database model. Without one common TypeORM layer, the services can drift and local startup becomes fragile.

## Scope

This story includes:

1. `packages/database/package.json`
2. `packages/database/tsconfig.json`
3. shared `DataSource`
4. initial entities
5. first migration

This story does not require complete business logic for all entities yet. It only needs the minimum structure required for the local baseline.

## Deliverables

1. `packages/database/src/data-source.ts`
2. initial entity files
3. `packages/database/src/migrations/0001-InitSchema.ts`

## Acceptance Criteria

1. `packages/database` compiles successfully
2. the shared `DataSource` can be imported by both API and worker
3. `npm run db:migrate` runs successfully against local PostgreSQL
4. the initial migration creates the minimum required tables for startup
5. TypeORM uses `synchronize: false`

## Dependencies

1. Story 1.1 completed

## Final Task

Create or update the necessary documentation inside `docs/` to reflect any setup steps, behavior, commands, or operational notes introduced by this story.

## Out Of Scope

1. advanced indexes for later performance tuning
2. complete domain behavior for later interview scenarios
